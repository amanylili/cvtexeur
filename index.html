Code LaTeX

« Ouvrir dans Overleaf » envoie le code LaTeX (et lui seul) à Overleaf, qui le compile en PDF. Vous pouvez aussi télécharger le fichier .tex et le compiler chez vous. Les modifications faites directement dans le code LaTeX sont remplacées si vous changez le contenu, le modèle ou une option.
